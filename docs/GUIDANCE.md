# Practical guidance

`guidance-1.0.0` is a deterministic presentation policy for saved fuzzy-3.0.0 and fuzzy-3.1.0 results. It does not change the stress calculation, its model hash, or saved observations. Check-in responses, revisions and exports derive guidance from each revision's original inputs and rule traces. The policy version is included separately. Unsupported models and failed assessments return an empty list. Scenarios do not present guidance as a real check-in recommendation.

Six authored action templates map the existing routine inputs to practical planning steps. Components are ordered by their recorded score contribution (component ID breaks ties). Within a component, only active medium/high-output rules are considered. Pressure inputs must have medium/high antecedents; sleep and relaxation must have low/medium antecedents. The eligible input with the largest sum of supporting firing strengths supplies one action. Template order breaks ties. There are at most three suggestions, each with the input value, component ID and actual supporting rule IDs. Firing strengths select actions; they are not causal attribution or probabilities.

When all components have only low outputs, one maintenance suggestion is shown instead of inventing a problem. Reported strain is never used to select actions. Suggestions have no promised score reduction and do not imply clinical validation. Screen-use advice distinguishes optional activity from essential use. Existing saved guidance is not persisted: a future presentation-policy update may change wording on old records, with its own policy version, while the original fuzzy assessment stays intact.
